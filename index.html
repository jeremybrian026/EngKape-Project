Features

Everything a café needs, nothing it doesn't

Built specifically for Engkape's Menu-Talaan. Every item, size, add-on, and payment method from the real menu — all in a fast, beautiful interface that works the first time you open it.

🛒
Smart ordering
Tap any item to open a size and add-on picker. Sizes auto-match drink or food type. Quantities update instantly. Add-ons attach to each line item individually.
☕
Full menu catalog
All 44 items across 11 categories — Coffee, Non-Coffee, Blended, Cheese Cloud, Starters, Sandwiches, Waffles, Rice Meals, and Buldak.
🌙
Light & dark mode
One-click toggle between warm cream light mode and deep dark mode. Preference saved to localStorage so it persists across sessions.
📊
Sales dashboard
Daily revenue, order counts, monthly trend charts, top-selling items, and payment method breakdown — all at a glance.
💳
4 payment methods
Cash, Card, GCash, and Maya. Select before charging. Success overlay confirms the transaction with amount and method.
✨
iOS-style UI
Rounded cards, spring pop-in modals, smooth 350ms theme transitions, amber gradient accents, and a live clock in the topbar.

  • Item count, subtotal, VAT, and total always visible
  • Qty controls on each line item — tap + or − to adjust

Sizes + add-ons in one popup

  • Drink add-ons only shown for drink items (Espresso Shot, Oat Milk, Syrup, Sea Salt Cream…)

Built with

Pure HTML — no dependencies

One self-contained HTML file. No frameworks, no build tools, no npm. Open it in any browser and it works.

📄
Plain HTML
Single .html file. No bundler, no build step. Drop it anywhere and open it.
🎨
CSS Variables
Full light/dark theming via CSS custom properties. Smooth transitions across every element.

Vanilla JS

Plus Jakarta Sans
